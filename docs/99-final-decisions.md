6. ## B. Game engine (answer to "engine or library?")
11. NO third-party game engine. Boards render with @shopify/react-native-skia (one <Canvas> per board; immediate-mode <Picture> recorded in a useDerivedValue worklet from pure draw functions; <Atlas> for many identical sprites; retained nodes for static art), animated with react-native-reanimated 4 + react-native-worklets, input via react-native-gesture-handler. All versions via `npx expo install` (SDK 57: Skia 2.6.2, Reanimated 4.5.1, Worklets 0.10.1, RNGH ~2.32.0). Shell/game-kit provide a small in-house kit: fixed-step loop, event→timeline, board layout + hit-testing, 2D geometry, seeded particles.
12. Turn-based architecture (≈24 of 26 games): pure engine `applyMove(state, move) → { state, events }` (+ create(seed, difficulty), listMoves, outcome) → pure `buildTimeline(events, motion) → Track[]` → worklet `sampleTimeline(tracks, tMs)` → worklet `draw(canvas, view, fx, colors, layout)`. JS pushes ONE "scene" shared value per move {view, tracks, startAt: -1}; the frame callback sets startAt = f.timestamp on its first frame and uses elapsed = f.timestamp - startAt (never timeSinceFirstFrame — it resets on reactivation: verified bug). Frame callback runs only while tracks are active. Save after applyMove, before animating. Input during animation fast-forwards or queues.
13. Real-time/continuous: (a) simulate-then-replay for resolution phases (Bank Shot volleys, Toggle Drop, cascades) inside applyMove with a fixed step, returning timestamped events; (b) fixed-timestep UI-thread loop for Halo Drift (accumulator, dt clamp ~250 ms, STEP_MS = 1000/120, typed arrays in shared values, events batched to JS once per frame via scheduleOnRN, inputs recorded as (tick, command) for replay).
14. DETERMINISM POLICY (lint-enforced in rules/sim/geom/levels folders): only + - * /, Math.sqrt, Math.imul, floor/round/abs/min/max; BAN Math.sin/cos/tan/atan2/exp/log/pow, Math.random, Date.now/new Date/performance.now. Integer PRNG (sfc32 or mulberry32 via Math.imul) stored in state. Reason: Hermes uses platform libm, Jest runs V8 → transcendental results differ; replays/daily seeds must match on every device.
15. Worklets: use the file-level `'worklet';` directive for sim/geom/layout/render modules (experimental but verified with SDK 57's babel preset), per-function directives as fallback; a test asserts UI-thread modules import only other UI-thread modules. scheduleOnRN (runOnJS is deprecated). Wrap frame-callback bodies in try/catch → pause game + local error log.
16. Gestures: RNGH 2.32 builder API on SDK 57, hidden behind ONE Shell hook `useBoardGestures(layout, handlers)`; move all board gestures to the v3 hook API together later (mixed relations not allowed). Pipeline: worklet hitTest(layout, x, y) → classifySwipe → InputIntent → scheduleOnRN → game's pure intentToMove(state, intent) → Move.
17. Physics: none in the Shell. In-house pure-TS `geom` kit (vec2, swept circle vs segment/AABB, circle-circle, spatial hash) obeying the determinism policy. Fallback only if ever needed: planck 1.5.0 (replays then approximate).
18. Boards never pixel-flip; RTL mirroring (opt-in per game) happens in BoardLayout mapping used by both draw and hitTest. Arabic-script text on boards via Skia Paragraph (TextDirection.RTL) with bundled Vazirmatn; digits localized in JS before drawing; drawText only for Latin/standalone digits. Board layout is a pure function of actual canvas size (any aspect: iPad landscape, iOS 27 resizable windows); goldens render boards at several sizes.
19. 120 Hz: `ios.infoPlist.CADisableMinimumFrameDurationOnPhone = true`; simulation always fixed-step; stop frame callbacks when idle. Lifecycle: stop frame callbacks + suspend AudioContext on background, during fullscreen ads, and when the Game screen loses focus; resume with clamped dt; auto-pause real-time games.
20. Sound: react-native-audio-api pinned EXACTLY 0.13.6 (pre-1.0; not in Expo's module map), SFX synthesized in code (pure synth/*.ts → Float32Array → AudioBuffer; Node script also writes WAVs for the owner to listen). AudioContext singleton, iOS session category 'ambient' (respects silent switch, mixes with user's music). Plugin options: iosBackgroundMode false, androidPermissions [], androidForegroundService false, disableFFmpeg true, disableStaticExternalLibs true. Do NOT install expo-audio. MUSIC OFF BY DEFAULT (resolves spec 8.7 "never over the player's music", since no API reports other audio). Watch first TestFlight upload for a missing-microphone-purpose-string warning (ITMS-90683); add a neutral NSMicrophoneUsageDescription only if flagged.
21. Haptics: expo-haptics (~57.0.3) behind a HapticsPort, gated by the Vibration setting, throttled ≥40 ms, `.catch(() => undefined)`. Hide the Vibration row on devices without haptics.
22. Code-drawn art pipeline: app icon, splash, store art and board previews rendered by headless Skia (Node) from the same draw functions; sprites pre-rendered to textures at startup; invalidate on theme/palette change.
