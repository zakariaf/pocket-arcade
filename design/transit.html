Transit

Every Pocket Arcade game is a line on one network. The Shell is the trunk they all share: Home, Levels, Daily, Statistics, Settings and Premium are stations every line stops at, and each game branches off to its own board.

So the screens borrow from metro maps and station signage: coloured lines that show where you have been and where you are going, circles for places you can stop, and sign-plate titles you read at a glance. A player sees their level progress the way a commuter reads the next stops.

A line means a path

Coloured lines appear only where there is order: levels to come, days played, tutorial steps, stars earned. Solid is travelled, dotted is still ahead. A line is never decoration.

Circles are stations

A circle is always a place: a level, a day, a step or a choice. A ring is open, a filled disc is where you are, a grey ring with a lock is closed. Shape carries the state, colour only confirms it.

Signs, not cards

Titles read like wayfinding: an arrow and a place name, set in a road-sign face and hung from the start edge. Panels are flat enamel plates with 2pt corners. Only sheets and dialogs cast a shadow.

One line colour per game

Each game owns one colour and uses it for its lines, its primary plate and the current station. Everything else stays ink, concrete and night, so three games feel like one network.

Avoids

  • Pill-shaped buttons and chips. Controls are 6pt plates; the only round things are stations and the “go” disc on the play plate.
  • Drop shadows on in-page panels, and one radius stamped on every block. Plates are flat; radius changes with role (2, 6, 20).
  • Accent-coloured body text, tinted panels and accent bars on cards. The line colour is kept for lines, the primary plate and the current station.
  • Gradients of any kind: on buttons, grounds, the splash or the Premium page.
  • Centred screen layouts. Everything hangs from the start edge, and flips with it in Persian and Sorani.
  • Free-angle icon strokes and decorative squiggles. Icon strokes run at 0°, 45° or 90° with circles for points, like the map.

Screens
