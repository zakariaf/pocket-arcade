Pocket Arcade Shell · design system proposal

Night Cabinet

Every Pocket Arcade app is a stand-up cabinet in a dark room. The game’s name glows on a backlit marquee, the menus sit behind a bezel like the tube of an old machine, and every count a player earns is posted like a high-score table. Each game lights the same cabinet with its own pair of glows: beam gold and rampart rose for Line Siege, clover and moonlight for Flock Tilt’s night pasture, arc cyan and weld orange for Scrap Shove’s sparks.

Lit, not painted

Surfaces stay dark aubergine; colour arrives as light: strokes and glows in the game’s duotone pair. In daylight the light becomes ink and flat print.

Numbers are the prize

Scores, stars and streaks are set as scoreboard numerals with unlit “8” segments behind them. Labels stay small and quiet.

One marquee, one bezel

The game name lives in the marquee; content lives inside one bezel; the main action sits in a control deck at the thumb. The banner stays outside the bezel.

Tables before cards

Stats, levels and settings read as ruled rows with dotted leaders. A lit card is spent only on what needs lifting: the daily challenge, a dialog, the Continue offer.

Avoids

  • Pill toggles and pill chips. Toggles are 6pt rectangular rockers with an I/O mark; badges are 3pt plates.
  • Neon on black. The ground is aubergine #1F1230, never #000, and no game gets a lone acid pop: every accent is a two-glow pair.
  • Soft grey drop shadows on every block. Elevation is light (glow) at night and an ink ring with a 4pt lip in daylight, only on pressable things.
  • Purple-to-blue gradients. The only gradient is the marquee backlight, drawn in the game’s own pair.
  • Centred menus. Titles and rows start-align; only the splash and the result hero are centred.
  • Glowing body copy. Glow is for numerals, the marquee and the current level; running text stays flat and readable.
  • Pulsing a Buy button. The attract pulse belongs to Play and the current level; Premium is never pushed.
  • Emoji and monospace. Icons are one 2pt mitred line set; numerals are condensed Tektur, not a code font.

Tokens

Every value here is a token the React Native theme module exports. The Shell owns the neutrals, type, spacing, radii, elevation and motion; a game module supplies only its duotone pair and its logo.

Per-game duotone

A is the lamp: primary button fill, the current level, lit stars, VU segments, group rules and scoreboard numerals. B is the halo: the outer glow ring around A, the marquee’s lower edge, the daily card, “New best!” and the Premium plate. At night both are light; in daylight A becomes a flat fill under ink (A-ink carries text), and B becomes an ink colour.

Type

Tektur Condensed carries the cabinet: marquee, titles, button labels, numerals. Barlow carries reading. fa and ckb switch every role to Vazirmatn at the same size, 1.5–1.6× line height, with no capitals and no letter-spacing (tracking breaks Arabic joining).

Strokes and elevation

Strokes: 1pt hairline rule, 1.5pt control edge, 2pt lit edge, 2pt dotted leader. Elevation is four light levels:

Motion

  • Marquee shimmer900ms sweep every 6s, cubic-bezier(.4,0,.2,1), in reading direction. Reduced: none; the marquee stays lit.
  • Attract pulseHalo 25%→100% over 1.6s, ease-in-out, alternate. Only Play and the current level. Reduced: steady halo at 80%.
  • Press90ms ease-out, sinks 3pt and the lip or glow tightens; release 140ms. Reduced: same (it is feedback, not motion).
  • Stars fill420ms each, 180ms stagger, overshoot cubic-bezier(.34,1.56,.64,1). Reduced: all stars appear at once.
  • Screen change240ms slide in reading direction, cubic-bezier(.2,.8,.2,1); mirrors in RTL. Reduced: 120ms cross-fade.
  • Busy8-tick spinner stepping at 800ms per turn. Reduced: 1600ms per turn.

Icons

One 24-unit grid, 2pt strokes, mitred joins and square caps, so they sit with Tektur’s cut corners. Solid fill only for transport (play, pause) and earned stars. Only back and next mirror in RTL; the clock, restore arrow, speaker and logos never do.

Components

Rendered live in the app theme, language and game chosen in the bar above. States sit side by side; nothing relies on hover. Buttons in this section are real and take keyboard focus.

Screens

Every Shell screen at 390 × 844 pt, scaled to fit; long screens run taller. The game board itself is out of scope: each game brings its own. Sample data: Level 12 in progress, 54 of 90 stars in pack 1, a 5-day streak (best 12), Saturday 26 Sep, and the store price “€1.99”.

Implementation notes for React Native

How Night Cabinet maps onto the stack in docs/05 and docs/10, without image assets, blur or runtime font loading.

Theme module

  • ColorTokens keeps its fields and maps directly: background = ground, surface = panel, text, textMuted = muted, primary = A, onPrimary = on-A, border = stroke, danger, icon = text, starOn = A, starOff = muted.
  • Add surfaceSunken (tube), rule, accentHalo (B), accentText (A-ink), haloText (B-ink), success, warning, focus, ghostDigit and scrim. A game palette file fills A, B, A-ink and B-ink for light and dark, plus the colour-blind pair; the Shell owns every neutral.
  • Elevation becomes ELEVATION.lit0..lit3 per scheme as React Native boxShadow strings (new architecture, several shadows with spread and inset). Dark: the glow stacks in the tokens table. Light: an ink ring plus a 4pt lip.
  • RADII becomes plate 3, control 6, button 10, panel 14, bezel 22; SPACING keeps the docs/05 scale and adds 48.

Icons, art and numerals

  • Icon data stays one path per icon on the 24 grid. Night Cabinet draws them as 2pt strokes, so the build step converts each once with Skia.Path.MakeFromSVGString(d).stroke({ width: 2, join: StrokeJoin.Miter, cap: StrokeCap.Square }) and stores the fill path, which keeps docs/05’s rasterize-and-tint Icon unchanged. DIRECTIONAL_ICONS = back, next.
  • Skia canvases (at most 8 per screen): the marquee (LinearGradient backlight plus a shimmer band moved by Reanimated), the logo, the result stars, the how-to picture. Level tiles, toggles, segments, VU sliders and the 7-day bars are plain Views.
  • ScoreDigits: each Latin digit sits in a fixed-width View (0.6 × font size) holding a ghost “8” in ghostDigit under the lit digit. Local digits (۰-۹) render as plain Vazirmatn text without the ghost.
  • Text glow is a single textShadow in A (React Native allows one); the B halo comes from the surrounding View’s boxShadow.

Fonts and layout

  • Bundled with the expo-font config plugin, never loaded at runtime: Tektur_Condensed-SemiBold, Tektur_Condensed-ExtraBold (display, titles, labels, numerals), Barlow-Regular, Barlow-SemiBold (body, captions), Vazirmatn-Regular, Vazirmatn-Bold (fa, ckb). Tektur and Barlow are SIL OFL 1.1 and get S11d rows.
  • scriptFontFor gains a face: 'display' | 'text' argument; each weight is its own family name, never fontWeight with a custom family. Latin display roles set textTransform: 'uppercase' and letter-spacing; Arabic-script roles set neither and use 1.5× line height.
  • Rows use flexDirection: 'row' with start/end only, so the 7-day strip, the bar chart, segment fills and the level grid mirror on their own. Gradient rules pick start/end colours from useDirection().
  • Every Pressable box is at least 44 × 44 pt as drawn: icon buttons 44, rows 52, segments 44, level tiles about 60 × 62, the hero Play 64 high.
