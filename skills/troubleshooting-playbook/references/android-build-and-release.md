# Android: toolchain, emulator and Google Play

Failures of the Android port: JDK, SDK, NDK and Gradle, prebuild, the variant inside Gradle, the emulator and adb, upload-key signing, the store-AAB gate, the Android Publisher API, and the Android gaps found in the iOS-first Shell. Rows marked "owner" are stops: send one message and never retry. Most rows come from Expo's, Gradle's and Google's documentation and wait for the first real Android build and release to be confirmed. Match the text you see in the Symptom column. Status: **verified** = seen and fixed in a real run; **documented** = read in the tool's own source or docs; **open** = not settled, the fix is the current fallback or decision. **owner** = stop and ask the owner, never work around it. Skill = where the full procedure lives.
